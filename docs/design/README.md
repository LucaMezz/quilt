# Design notes

Each note records one decision: the context, what was chosen, and the options
that were rejected and why. Notes are numbered in the order they were written
and are never renumbered.

| Status | Meaning |
| --- | --- |
| Draft | Being written; open for change |
| Accepted | Decided; the code follows it |
| Superseded | Replaced by a later note, linked at the top |
