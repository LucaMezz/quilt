# Security Policy

## Supported Versions

Quilt has not had a release yet, so only the latest commit on `main`
receives security fixes. Once releases start, only the latest 0.x
release will be supported, because each minor version may contain
breaking changes.

## Reporting a Vulnerability

Please don't report security vulnerabilities via public issues,
discussions, or pull requests.

Report them privately through GitHub instead: open the **Security**
tab and click **Report a vulnerability**, or visit 
[this form](https://github.com/LucaMezz/quilt/security/advisories/new)
directly.

Please include:

- the affected component (API, controller, CLI or dashboard) and the commit or version
- steps to reproduce, or a proof of concept
- what an attacker could do with it

What to expect:

Since this is primarily a portfolio project at the moment, I will attempt
to acknowledge and investigate the issue as soon as possible, but
there is no guaranteed time frame.
